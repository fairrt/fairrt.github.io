快速上手示例

只需几行代码，即可在 Canvas 上渲染一个旋转的立方体。

import { Engine, Scene, ArcRotateCamera, MeshBuilder, Color3 } from '@babylonjs/core';

// 初始化引擎
const engine = new Engine(document.getElementById('renderCanvas'), true);

const createScene = function() {
    const scene = new Scene(engine);

    // 摄像机
    const camera = new ArcRotateCamera('Camera', Math.PI / 2, Math.PI / 2, 3, Vector3.Zero(), scene);
    camera.attachControl(document.getElementById('renderCanvas'), true);

    // 灯光
    new HemisphericLight('light', Vector3.Zero(), scene);

    // 立方体
    const box = MeshBuilder.CreateBox('box', {size: 1}, scene);
    box.material = new StandardMaterial('boxMat', scene);
    box.material.diffuseColor = Color3.Red();

    return scene;
};

const scene = createScene();

scene.executeWhenReady(function () {
    engine.runRenderLoop(function () {
        scene.render();
    });
});

常见问题解答

babylon中文版和 Unity WebGL 有什么区别？

Babylon.js 是基于 JavaScript 的纯前端引擎，无需安装客户端即可运行，非常适合轻量级 3D 网页应用。而 Unity WebGL 通常用于将大型游戏移植到网页，文件体积较大，性能优化较为复杂。

如何开始学习 Babylon.js？

建议从官方文档的“Getting Started”章节入手，运行官方提供的示例代码。掌握基本概念（如场景、摄像机、网格）后，可以参考官方画廊中的高级教程。

支持 WebGPU 吗？

是的，Babylon.js 正在积极支持 WebGPU，并在最新的 babylon中文版版本中提供了相应的 API 和着色器语言支持，以提供更极致的性能。
